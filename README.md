# Biblioteca Particular W&D

## Instalação Local

1. Clone o repositório.
2. Crie um arquivo `.env` na raiz com:
   ```
   API_KEY=sua_chave_gemini
   SUPABASE_URL=sua_url_supabase
   SUPABASE_ANON_KEY=sua_key_supabase
   ```
3. Rode `npm install`
4. Rode `npm run dev`

## Deploy na Vercel

1. Importe o projeto.
2. Adicione as Environment Variables (API_KEY, SUPABASE_URL, SUPABASE_ANON_KEY).
3. Deploy.
